# 张浩堃 · 个人主页

一个无需构建工具的静态个人主页，可部署到 GitHub Pages。

## 仓库名

个人主页仓库应命名为 `zhanghaok.github.io`。

## 发布说明

1. 打开仓库 **Settings → Pages**。
2. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/(root)`，保存。
3. 等待 GitHub Pages 构建完成后访问 `https://zhanghaok.github.io/`。

> 注意：GitHub Pages 面向公众提供网页。即使仓库是私有的，已发布的网站仍然可以被任何人访问。个人账号使用 GitHub Free 时，Pages 需要公开仓库；私有仓库启用 Pages 需要符合 GitHub Pro 等计划条件。若你的目标是让主页仅自己或指定的人可见，GitHub Pages 不适合这个需求。

## 修改内容

编辑 `index.html`，更新姓名、简介及希望展示的链接即可。目前页面只展示姓名和职业，没有添加虚构的联系方式或社交账号。
